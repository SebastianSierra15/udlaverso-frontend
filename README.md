# UdlaVerso Frontend

Frontend de UdlaVerso, una plataforma web para la comunidad de la Universidad de la Amazonia.

## Demo

[Ver aplicación desplegada](https://udlaverso-frontend.vercel.app)

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Framer Motion
- Recharts

## Desarrollo local

```bash
npm install
npm run dev
```

## Verificación y build

```bash
npm run lint
npm run build
```

## Configuración

Copia `.env.example` a `.env` y completa únicamente las variables necesarias para el entorno local.
